## 1. 钱包创建

### 第一次启动

```bash
cd D:\ai\Claudos
python -m trading_agent.main
```

首次启动时，程序检测到没有钱包配置文件，会询问是否创建钱包。输入 `Y` 即可自动生成。

### 手动创建

在手动模式下输入：
```
> 创建钱包
```

### 技术原理

钱包使用以太坊官方 Python 库 `eth_account` 生成：

- **私钥**：64 位十六进制随机数（256 位熵）
- **地址**：从私钥推导出的 20 字节以太坊地址（0x 开头，42 位）
- **算法**：secp256k1 椭圆曲线加密

Hyperliquid 兼容以太坊地址格式，因此生成的地址可以直接在 Hyperliquid 使用。

### 钱包文件位置

```
trading_agent/data/config.json

{
    "wallet_private_key": "0x...",  ← 私钥，谁拿到谁控制你的钱
    "wallet_address": "0x..."       ← 地址，公开信息，用来接收资金
}
```

> **⚠️ 私钥存在你本地，不要外传**。`data/config.json` 已加入 `.gitignore`，不会提交到 GitHub。

## 2. 存入资金

### 从交易所提现

```
交易所（币安/欧易等）
  → 提 USDC
  → 网络选择: Arbitrum One
  → 地址: 你的 0x... 钱包地址
  → 确认提现
```

### 从已有 Hyperliquid 账户转入

登录 [app.hyperliquid.xyz](https://app.hyperliquid.xyz) → Transfer → 输入地址和金额。

### 最低金额建议

| 目的 | 建议金额 |
|---|---|
| 测试流程 | $20 |
| 正常交易 | $100+ |
| 低频小仓 | $50 |

链上实际扣款 = 转账金额 + 网络费（约 $0.1-0.5）

## 3. 启动智能体

### 手动模式（默认）

```bash
cd D:\ai\Claudos
python -m trading_agent.main
```

AI 会看市场、给建议，但**是否交易取决于你输入的指令**。

### 自动模式

```bash
python -m trading_agent.main --auto
```

AI **自主决策**，每 5 分钟检查一次市场。它会：
1. 查当前行情、持仓、余额
2. 回想历史相关教训
3. 决定是否开仓/平仓
4. 平仓后自动复盘、提取教训

在自动模式下按回车键可切回手动模式。

---

## 4. 手动模式命令

| 命令 | 作用 |
|---|---|
| `创建钱包` | 生成新的 Hyperliquid 钱包 |
| `状态` | 查看账户余额和持仓 |
| `复盘` | 分析近期交易，提取教训 |
| `教训` | 查看所有历史教训 |
| `自动` | 切换到自动运行模式 |
| `exit` | 退出 |

### AI 自然语言指令

除了上述命令，你可以直接跟 AI 对话：

```
> 看看 BTC 现在什么情况
> 我想开 100U 的 ETH 多单
> 把 BTC 空单平掉
> 今天赚了多少？
```

AI 会自主调用工具查询市场、执行交易，然后回复你。

## 5. 自动模式

### 运行周期

```
每 5 分钟：
  1. 查余额和持仓
  2. 查主流币种行情
  3. 向量搜索相关历史教训
  4. DeepSeek 分析决策
  5. 执行交易（如有）
  6. 保存新教训（如有）
  7. 等待下一周期

每 6 小时：
  运行一次完整复盘
```

### 周期配置

编辑 `trading_agent/config.py`：

```python
AUTO_TRADE_INTERVAL = 300       # 检查间隔（秒）
DAILY_LOSS_LIMIT_PCT = -5       # 日亏损 -5% 自动停止
MAX_POSITION_SIZE_PCT = 10      # 单笔最大 10%
MAX_LEVERAGE = 3                # 最高 3 倍杠杆
```

## 6. 复盘系统

### 触发方式

- 自动：自动模式下每 6 小时运行一次
- 手动：输入 `复盘` 命令

### 复盘内容

```
1. 读取近期交易记录
2. 统计：总交易数、总盈亏、胜率
3. AI 分析：找出问题，给出改进建议
4. 提取教训：自动存入教训记忆库
```

### 交易记录格式

每条交易记录包含：

```json
{
    "id": 1,
    "coin": "ETH",
    "side": "long",
    "size": 0.1,
    "usd_size": 25,
    "entry_price": 2500,
    "leverage": 1,
    "open_time": "2026-06-10T...",
    "pnl": 3.5
}
```

保存在 `data/trades.json`。

## 7. 教训记忆系统

### 工作原理

```
复盘时：
  AI 分析 → 提取教训 → 中文向量模型（BAAI/bge-small-zh-v1.5）
  → 转成向量 → 存入 lessons.json

交易时：
  当前市场情况 → 转成向量 → 搜索最相似的历史教训
  → 把相关教训放进 DeepSeek 提示词
  → AI 决策前先看到过去的经验
```

### 向量搜索示例

```
教训：BTC 在30分钟内涨幅超3%时追多，80%概率被套

搜索"BTC price pumping fast" → 匹配度 0.50 → 命中此教训
搜索"凌晨交易" → 匹配度 0.77 → 命中"凌晨交易量低"的教训
```

### 查看教训

```
> 教训
  #1 2026-06-10 BTC 在30分钟内涨幅超3%时追多...
  #2 2026-06-10 凌晨 2-5 点交易量低，不适合开仓...
```

保存在 `data/lessons.json`。

## 8. 安全机制

| 机制 | 说明 |
|---|---|
| 私钥本地存储 | 存在 `config.json`，不入 git |
| 单笔仓位限制 | 默认不超过总资金 10% |
| 止损杠杆限制 | 最高 3 倍杠杆 |
| 每日止损 | 日亏损达 -5% 停止自动交易 |
| 指令拦截 | 自动模式中按回车立即切回手动 |

> **风险提示**：永续合约交易有高风险，本软件仅供学习参考，不构成投资建议。

## 9. 文件说明

├── trading_agent/
│   ├── config.py          # 配置：API key、杠杆、仓位限制

├── README.md

### 各模块关系

```
main.py（你操作的界面）
  ↓
agent.py（ReAct 大脑，用 DeepSeek 决策）
  ↓
hl_connector.py → Hyperliquid 链
memory.py → data/lessons.json（教训记忆）
             data/trades.json（交易记录）
```
